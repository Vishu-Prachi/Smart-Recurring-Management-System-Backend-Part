Backend (Spring Boot):

-Developed backend using Spring Boot to handle business logic for the Recurring Deposit system
-Designed and implemented RESTful APIs for seamless communication with the ReactJS frontend
-Created custom APIs for RD account creation, deposit handling, and passbook tracking
Implemented two main data models:
-RD User – manages user details and account information
-RD Passbook – tracks transaction history and monthly deposits
-Used Spring Data JPA for database operations and entity management
-Implemented CRUD operations for RD accounts and transactions
-Built interest and maturity calculation logic for recurring deposits
-Ensured clean architecture with Controller → Service → Repository layers
-Used Gradle for dependency management and build automation
-Integrated backend APIs with frontend for real-time data updates
-Added basic validation and error handling for secure API usage
